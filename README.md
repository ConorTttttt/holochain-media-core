# Holochain Media Core

Shared, file-type-independent content contracts and security interfaces for Holochain media applications. The implementation is being developed in reviewable changes; see the `feat/core-001-bootstrap` branch for the first workspace and architecture proposal.

**Status:** pre-release. No storage, encryption, payment, publication approval, or entitlement enforcement is provided by this bootstrap README. No public Holochain DHT entry should contain media payloads or plaintext content keys.
